# IONOS

Großer deutscher Hoster. Der Schlüssel besteht aus zwei Teilen, durch einen Punkt verbunden.

Website: <https://www.ionos.com>

Einordnung: deutschsprachig, DNS-Anbieter

## Was der Anbieter kann

| | |
|---|---|
| IP-Versionen | IPv4 und IPv6 |
| IPv6-Suffix | ja |
| TTL einstellbar | nein |
| Proxy-Schalter | nein |

## Felder

| Feld | Beschriftung | Typ | Nötig | Bedeutung |
|---|---|---|---|---|
| `api_key` | API-Key (Prefix.Secret) | Zugangsdaten | erforderlich | Kein Passwort, sondern ein Schlüssel aus zwei Teilen. Im IONOS Developer Portal unter "Create New Key" erzeugen und Prefix und Secret durch einen Punkt getrennt eintragen. |
