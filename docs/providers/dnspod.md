# DNSPod

Chinesischer DNS-Anbieter. Der Token besteht aus ID und Schlüssel, durch Komma getrennt.

Website: <https://www.dnspod.cn>

Einordnung: DNS-Anbieter

## Was der Anbieter kann

| | |
|---|---|
| IP-Versionen | IPv4 und IPv6 |
| IPv6-Suffix | ja |
| TTL einstellbar | nein |
| Proxy-Schalter | nein |

## Felder

| Feld | Beschriftung | Typ | Nötig | Bedeutung |
|---|---|---|---|---|
| `token` | API-Token | Zugangsdaten | erforderlich | Achte auf das Format: ID und Token zusammen, durch ein Komma getrennt, etwa 730060,e1a8a…553d. Im DNSPod-Konto als API-Token erzeugen. Es ist nicht das Konto-Passwort. |
