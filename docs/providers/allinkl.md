# ALL-INKL.COM

Deutscher Webhoster mit eigener DDNS-Funktion, die im KAS je Benutzer eingerichtet wird.

Website: <https://all-inkl.com>

Einordnung: deutschsprachig, DNS-Anbieter

## Was der Anbieter kann

| | |
|---|---|
| IP-Versionen | IPv4 und IPv6 |
| IPv6-Suffix | ja |
| TTL einstellbar | nein |
| Proxy-Schalter | nein |

## Felder

| Feld | Beschriftung | Typ | Nötig | Bedeutung |
|---|---|---|---|---|
| `username` | DDNS-Benutzername | Text | erforderlich | Nicht dein KAS-Login. All-Inkl vergibt beim Anlegen eines DDNS-Benutzers automatisch einen Namen, der meist mit "dyn" und Ziffern beginnt. Zu finden im KAS unter Tools → DDNS-Einstellungen. Beispiel: `dynXXXXXXX`. |
| `password` | DDNS-Passwort | Zugangsdaten | erforderlich | Nicht dein KAS-Passwort. Dieses vergibst du selbst, wenn du im KAS unter Tools → DDNS-Einstellungen einen neuen DDNS-Benutzer anlegst. |
