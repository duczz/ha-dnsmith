# GoIP.de

Kostenloser deutscher DDNS-Dienst. Die Zugangsdaten werden je Router vergeben, nicht je Konto.

Website: <https://www.goip.de>

Einordnung: deutschsprachig, kostenlos, DynDNS2

## Was der Anbieter kann

| | |
|---|---|
| IP-Versionen | IPv4 und IPv6 |
| TTL einstellbar | nein |
| Proxy-Schalter | nein |

## Felder

| Feld | Beschriftung | Typ | Nötig | Bedeutung |
|---|---|---|---|---|
| `username` | Router-Benutzername | Text | erforderlich | Nicht dein Webzugang-Login. GoIP erzeugt je Router eigene Zugangsdaten; nur die funktionieren in der Update-URL. Sie stehen in der Routerliste unter goip.de. |
| `password` | Router-Passwort | Zugangsdaten | erforderlich | Das Passwort zum Router-Benutzernamen, nicht das des Administrationsbereichs. Ebenfalls in der Routerliste, dort über das Augensymbol sichtbar. |
