# Joker.com

Registrar aus Deutschland. DynDNS steht für jede dort verwaltete Domain zur Verfügung und spricht das klassische DynDNS2-Protokoll.

Website: <https://joker.com>

Einordnung: Registrar, deutschsprachig, DynDNS2

## Was der Anbieter kann

| | |
|---|---|
| IP-Versionen | IPv4 und IPv6 |
| IPv6-Suffix | nein |
| TTL einstellbar | nein |
| Proxy-Schalter | nein |

## Felder

| Feld | Beschriftung | Typ | Nötig | Bedeutung |
|---|---|---|---|---|
| `username` | DynDNS-Benutzername | Text | erforderlich | Nicht die Anmeldedaten deines Joker.com-Kontos. Benutzername und Passwort werden im Kundenbereich eigens für DynDNS erzeugt und sehen aus wie eine zufällige Zeichenfolge. |
| `password` | DynDNS-Passwort | Zugangsdaten | erforderlich | Wird zusammen mit dem Benutzernamen im Kundenbereich erzeugt. |

## Hinweise

> DynDNS muss je Domain im Kundenbereich unter "DNS" erst eingeschaltet werden; erst dann erscheinen Benutzername und Passwort.
