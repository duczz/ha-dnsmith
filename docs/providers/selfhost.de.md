# selfHOST

Deutscher DDNS-Dienst. Je Hostname wird ein eigener Account mit eigenen Zugangsdaten angelegt.

Website: <https://www.selfhost.de>

Einordnung: deutschsprachig, kommerziell, DynDNS2

## Was der Anbieter kann

| | |
|---|---|
| IP-Versionen | IPv4 und IPv6 |
| IPv6-Suffix | ja |
| TTL einstellbar | nein |
| Proxy-Schalter | nein |

## Felder

| Feld | Beschriftung | Typ | Nötig | Bedeutung |
|---|---|---|---|---|
| `username` | DynDNS-Benutzername | Text | erforderlich | Gehört zum jeweiligen DynDNS-Account, nicht zur Webseiten-Anmeldung. Im Kundenmenü unter "DynDNS-Accounts" → "Details" zu finden. |
| `password` | DynDNS-Kennwort | Zugangsdaten | erforderlich | Steht ebenfalls unter "DynDNS-Accounts" → "Details" und lässt sich dort neu setzen. |
