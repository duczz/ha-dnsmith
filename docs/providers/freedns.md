# FreeDNS

Kostenloser Dienst mit vielen gemeinschaftlich geteilten Domains. Das Update läuft über einen Token aus der persönlichen Sync-Adresse.

Website: <https://freedns.afraid.org>

Einordnung: kostenlos

## Was der Anbieter kann

| | |
|---|---|
| IP-Versionen | IPv4 und IPv6 |
| IPv6-Suffix | ja |
| TTL einstellbar | nein |
| Proxy-Schalter | nein |

## Felder

| Feld | Beschriftung | Typ | Nötig | Bedeutung |
|---|---|---|---|---|
| `token` | Update-Token | Zugangsdaten | erforderlich | Der Token aus der Update-Adresse, die FreeDNS für den Eintrag anzeigt. Du kannst die ganze Adresse einfügen (https://sync.afraid.org/u/…/) — DNSmith nimmt sich den Token selbst heraus. |
