# myaddr.tools

Minimalistischer kostenloser Dienst: eine Subdomain, ein Schlüssel, kein Konto.

Website: <https://myaddr.tools>

Einordnung: kostenlos

## Was der Anbieter kann

| | |
|---|---|
| IP-Versionen | IPv4 und IPv6 |
| IPv6-Suffix | ja |
| TTL einstellbar | nein |
| Proxy-Schalter | nein |

## Felder

| Feld | Beschriftung | Typ | Nötig | Bedeutung |
|---|---|---|---|---|
| `key` | Schlüssel | Zugangsdaten | erforderlich | Den Schlüssel bekommst du bei der Registrierung der Subdomain. Ein Konto-Passwort gibt es nicht — wer den Schlüssel hat, kontrolliert den Namen. Geht er verloren, ist die Subdomain weg. |
