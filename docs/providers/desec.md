# deSEC

Kostenloser DNS-Dienst aus Deutschland, gemeinnützig getragen und durchgehend mit DNSSEC.

Website: <https://desec.io>

Einordnung: kostenlos, DNS-Anbieter, IPv6-orientiert

## Was der Anbieter kann

| | |
|---|---|
| IP-Versionen | IPv4 und IPv6 |
| TTL einstellbar | nein |
| Proxy-Schalter | nein |

## Felder

| Feld | Beschriftung | Typ | Nötig | Bedeutung |
|---|---|---|---|---|
| `token` | API-Token | Zugangsdaten | erforderlich | Nicht dein deSEC-Konto-Passwort, sondern ein eigenes API-Token. Du bekommst es bei der Registrierung oder legst es später in der Token-Verwaltung an. |

## Ratenbegrenzung

deSEC begrenzt DynDNS-Updates auf zwei Anfragen je zwei Minuten und Domain.

Kürzestes sinnvolles Intervall: 60s.
