# Domeneshop

Norwegischer Registrar mit eigener API aus Token und Secret.

Website: <https://domene.shop>

Einordnung: Registrar

## Was der Anbieter kann

| | |
|---|---|
| IP-Versionen | IPv4 und IPv6 |
| IPv6-Suffix | ja |
| TTL einstellbar | nein |
| Proxy-Schalter | nein |

## Felder

| Feld | Beschriftung | Typ | Nötig | Bedeutung |
|---|---|---|---|---|
| `token` | API-Token | Zugangsdaten | erforderlich | Nach dem Login im Kontrollpanel unter API erzeugen. Nicht dein Login-Name. |
| `secret` | API-Secret | Zugangsdaten | erforderlich | Entsteht im selben Schritt wie der Token und wird nur dort einmal angezeigt. Nicht dein Konto-Passwort. |
