# Anbieter

DNSmith kennt 64 Anbieter: 62 anbieterspezifische und 2 generische Einträge, die alles abdecken, was hier nicht eigens aufgeführt ist.

Diese Seiten werden aus `dnsmith/providers/*.yaml` erzeugt — derselben Quelle, aus der die Oberfläche ihre Formulare baut. Sie können deshalb nicht auseinanderlaufen.
