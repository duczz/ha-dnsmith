# INWX

Deutscher Registrar. Der DynDNS-Zugang wird getrennt vom Kundenkonto angelegt.

Website: <https://www.inwx.com>

Einordnung: deutschsprachig, Registrar

## Was der Anbieter kann

| | |
|---|---|
| IP-Versionen | IPv4 und IPv6 |
| TTL einstellbar | nein |
| Proxy-Schalter | nein |

## Felder

| Feld | Beschriftung | Typ | Nötig | Bedeutung |
|---|---|---|---|---|
| `username` | DynDNS-Benutzername | Text | erforderlich | Nicht dein INWX-Konto-Login. Im Kundenkonto links unter "DynDNS" per "Konto hinzufügen" einen eigenen Zugang anlegen; den Benutzernamen vergibst du dabei selbst. |
| `password` | DynDNS-Passwort | Zugangsdaten | erforderlich | Das Passwort dieses DynDNS-Zugangs, nicht dein INWX-Kontopasswort. |
