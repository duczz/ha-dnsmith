# dynv6

Kostenloser DDNS-Dienst, der von Anfang an für IPv6 gebaut wurde. Unterstützt auch Präfix-Delegation.

Website: <https://dynv6.com>

Einordnung: kostenlos, IPv6-orientiert, deutschsprachig

## Was der Anbieter kann

| | |
|---|---|
| IP-Versionen | IPv4 und IPv6 |
| IPv6-Suffix | ja |
| TTL einstellbar | nein |
| Proxy-Schalter | nein |

## Felder

| Feld | Beschriftung | Typ | Nötig | Bedeutung |
|---|---|---|---|---|
| `token` | HTTP-Token | Zugangsdaten | erforderlich | Unter dynv6.com/keys als "HTTP Token" zu finden. Nicht der SSH-Key und nicht das Account-Passwort. |

## Hinweise

> Für reine IPv6-Anschlüsse eine der zuverlässigsten Wahlen.
