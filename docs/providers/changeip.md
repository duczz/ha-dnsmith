# ChangeIP

Älterer DDNS-Dienst mit kostenlosem und kostenpflichtigem Tarif.

Website: <https://www.changeip.com>

Einordnung: kostenlos, kommerziell, DynDNS2

## Was der Anbieter kann

| | |
|---|---|
| IP-Versionen | IPv4 und IPv6 |
| TTL einstellbar | nein |
| Proxy-Schalter | nein |

## Felder

| Feld | Beschriftung | Typ | Nötig | Bedeutung |
|---|---|---|---|---|
| `username` | Benutzername | Text | erforderlich | Dein ChangeIP-Kontoname. Bei Gratis-Konten ist das oft eine vergebene Kennung der Form dynXXXXXXX. Beispiel: `dynXXXXXXX`. |
| `password` | Konto-Passwort | Zugangsdaten | erforderlich | Das Passwort deines ChangeIP-Kontos. Ein getrenntes Update-Passwort gibt es hier nicht. |
