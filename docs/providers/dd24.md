# domaindiscount24

Deutscher Registrar. Dynamic DNS wird je Subdomain eingeschaltet.

Website: <https://www.domaindiscount24.com>

Einordnung: deutschsprachig, Registrar

## Was der Anbieter kann

| | |
|---|---|
| IP-Versionen | IPv4 und IPv6 |
| IPv6-Suffix | ja |
| TTL einstellbar | nein |
| Proxy-Schalter | nein |

## Felder

| Feld | Beschriftung | Typ | Nötig | Bedeutung |
|---|---|---|---|---|
| `password` | Dynamic-DNS-Passwort | Zugangsdaten | erforderlich | Nicht dein Kundenkonto-Passwort. Du vergibst es beim Aktivieren von Dynamic DNS: Domains → Meine Domains → Domain wählen → Reiter "Dynamic DNS". Dort lässt es sich auch neu setzen. |
