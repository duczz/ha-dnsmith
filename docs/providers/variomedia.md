# Variomedia

Deutscher Hoster mit einem eigenen Passwort für die DNS-Einstellungen.

Website: <https://www.variomedia.de>

Einordnung: deutschsprachig, DNS-Anbieter

## Was der Anbieter kann

| | |
|---|---|
| IP-Versionen | IPv4 und IPv6 |
| TTL einstellbar | nein |
| Proxy-Schalter | nein |

## Felder

| Feld | Beschriftung | Typ | Nötig | Bedeutung |
|---|---|---|---|---|
| `email` | E-Mail-Adresse des Kundenaccounts | E-Mail | erforderlich | Dieselbe Adresse, mit der du dich bei Variomedia anmeldest. Beispiel: `email@domain.com`. |
| `password` | Passwort der DNS-Einstellungen | Zugangsdaten | erforderlich | Ausdrücklich nicht das Passwort deines Kundenaccounts, sondern ein eigenes Passwort für die DNS-Einstellungen. Es wird im Kundenmenü bei den DNS-Einstellungen gesetzt. |
