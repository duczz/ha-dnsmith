# Hurricane Electric

Kostenloser DNS-Dienst mit starkem IPv6-Schwerpunkt. Je Eintrag wird ein eigener Schlüssel erzeugt.

Website: <https://dns.he.net>

Einordnung: kostenlos, DNS-Anbieter, IPv6-orientiert

## Was der Anbieter kann

| | |
|---|---|
| IP-Versionen | IPv4 und IPv6 |
| IPv6-Suffix | ja |
| TTL einstellbar | nein |
| Proxy-Schalter | nein |

## Felder

| Feld | Beschriftung | Typ | Nötig | Bedeutung |
|---|---|---|---|---|
| `password` | DDNS-Schlüssel | Zugangsdaten | erforderlich | Nicht dein dns.he.net-Passwort. Am A- oder AAAA-Eintrag die Option "enable entry for dynamic dns" setzen und den Schlüssel danach über das Generate-Symbol erzeugen. Er gilt je Hostname. |
