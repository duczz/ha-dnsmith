# STRATO

Großer deutscher Hoster. Als Benutzername dient eine Domain aus dem eigenen Paket, nicht ein Login-Name.

Website: <https://www.strato.de>

Einordnung: deutschsprachig, DNS-Anbieter

## Was der Anbieter kann

| | |
|---|---|
| IP-Versionen | IPv4 und IPv6 |
| TTL einstellbar | nein |
| Proxy-Schalter | nein |

## Felder

| Feld | Beschriftung | Typ | Nötig | Bedeutung |
|---|---|---|---|---|
| `password` | DynDNS-Passwort | Zugangsdaten | erforderlich | Nicht dein STRATO-Kundenpasswort. Ein eigenes DynDNS-Passwort vergibst du im Kunden-Login unter "Sicherheit" → "Passwörter festlegen". DynDNS selbst schaltest du bei der Domain unter DNS → Dynamic DNS frei. |
